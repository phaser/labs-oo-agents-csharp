# labs-oo-agents-csharp

A C# / .NET port of [NVIDIA Object Oriented Agents (NOOA)](https://github.com/NVIDIA-NeMo/labs-OO-Agents).
In NOOA an agent is a class: fields are state, methods are capabilities, doc comments are prompts, and types are contracts.

Status: planning. See [`work/index.md`](work/index.md).
